# Test-repo

A simple test repository used to demonstrate and practice common Git and GitHub workflows.

## 📋 About This Repository

This repository was created as a sandbox environment for exploring version control concepts and collaboration workflows using Git and GitHub. It serves as a hands-on playground for:

- Creating and managing branches
- Writing and committing code changes
- Opening and reviewing Pull Requests (PRs)
- Approving and merging PRs
- Deleting branches after merging

## 📁 Files

| File | Description |
|------|-------------|
| `README.md` | Project overview and documentation |
| `about.htm` | An HTML page with information about the project, styled with CSS |

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/ngk90/Test-repo.git
   ```

2. **Create a new branch**
   ```bash
   git checkout -b your-branch-name
   ```

3. **Make changes, commit and push**
   ```bash
   git add .
   git commit -m "Your commit message"
   git push origin your-branch-name
   ```

4. **Open a Pull Request** on GitHub and request a review.

## 🛠️ Tech Stack

- **HTML5** – for the `about.htm` page
- **CSS3** – inline styling within the HTML file
- **Git & GitHub** – version control and collaboration
